# First 7 Days with OpenClaw

You installed OpenClaw. You typed "hello." It replied. Now what?

This series takes you from first conversation to power user in 7 steps. Each "day" is a self-contained guide you can finish in under an hour. Do them at your own pace — one per day, or all in an afternoon.

| Day | What You'll Learn | Time |
|-----|------------------|------|
| [**Day 1: Make It Yours**](day-1-make-it-yours) | Personalize your bot's identity and have your first real conversation | 30 min |
| [**Day 2: Your Daily Driver**](day-2-daily-driver) | Put it to work — summaries, research, file management | 30 min |
| [**Day 3: Set It Free**](day-3-automation) | Automate tasks with the heartbeat — morning briefings, monitoring | 45 min |
| [**Day 4: Supercharge It**](day-4-skills) | Install community skills from ClawHub | 30 min |
| [**Day 5: Be Everywhere**](day-5-multi-channel) | Connect multiple platforms and route between them | 45 min |
| [**Day 6: Build Your Own**](day-6-power-moves) | Create custom skills, set up cron jobs, go multi-agent | 60 min |
| [**Day 7: Lock It Down**](day-7-production) | Security hardening, cost optimization, monitoring | 45 min |

:::tip
**Already past the basics?** Jump to whatever day matches your level. Each guide stands alone.
:::

## Prerequisites

- OpenClaw installed and running (`openclaw status` shows green)
- At least one channel connected (Telegram recommended for easiest start)
- An LLM configured (any provider works — see [Model Selection Guide](/guides/model-selection))

## What You'll Have After Day 7

- A personalized AI assistant with a distinct identity
- Daily automated briefings and monitoring
- Multiple chat platforms connected
- Community skills installed and working
- At least one custom skill you built yourself
- A production-hardened, cost-optimized setup

Let's get started.
